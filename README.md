# ॐ Banarasi Babu — Living Digital Kashi Platform 🛕✨

> **An immersive, 4K Living Digital Companion & Cultural Encyclopedia for Varanasi (Kashi)**  
> *Authentic 88 Ghats Atlas · Sacred Temples · Heritage & Universities · Famous Food & Mithai · AI Concierge*

---

## 🌟 Key Highlights & Features

1. **4K Living Dynamic Backgrounds & 9 Sacred Themes:**
   - Real high-resolution photography with ambient particle animations and theme-adaptive atmospheric transitions:
     - 🏛️ *Classic Kashi* (Daylight Golden Hour)
     - 🌊 *Ganga Flow* (Aquamarine River View)
     - 🕉️ *Masan Holi* (Manikarnika Sacred Pyre Ash)
     - 🌸 *Rangbhari Ekadashi* (Gauna Utsav & Gulal)
     - 🏮 *Banaras Ki Galiyan* (Ancient Silk & Brass Alleyways)
     - 🪔 *Ganga Aarti* (Dashashwamedh Maha Aarti)
     - ✨ *Dev Diwali* (1 Million Clay Diyas)
     - 🔱 *Bhasma Aarti* (Aghor Shiv Naad)
     - 🌙 *Mahashivratri* (Midnight Shiv Baraat)

2. **The 88 Ghats Living Atlas & Proximity Radar:**
   - Full historical and spiritual documentation for all 88 sacred ghats along the crescent Ganga.
   - Interactive 500m proximity graph linking nearby ghats, temples, and street vendors.

3. **Interactive Living Map of Kashi:**
   - Dynamic Leaflet-powered GIS map plotted with 25+ ground-verified pins across Ghats, Temples, BHU, UP College, Harish Chandra, Sarnath, and Ramnagar Fort with live camera zoom (`flyTo`).

4. **Ask Banarasi Babu — Grounded AI Concierge:**
   - Instant cultural recommendations, darshan booking guidance, dawn boat routes, and kachori trails.

5. **Live Sacred Status & Weather Engine:**
   - Real-time weather via Open-Meteo API, Ganga water temperature, and upcoming Aarti countdowns.

## 🚀 Getting Started

Simply clone the repository and open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/divakarpandey07/banarasi-babu.git

# Navigate into project directory
cd banarasi-babu

# Open in browser or local web server
open index.html
```
